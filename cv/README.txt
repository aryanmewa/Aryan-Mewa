CV
--
Put your CV here as a PDF. The most recently added PDF is used.

After adding it, double-click  update-photos.command  (in the main folder) and refresh
the website. The "Download Curriculum Vitae (PDF)" button then appears on the Contact page
and downloads this file. To update your CV later, drop in the new PDF and run the script again.
With no PDF in this folder, the button stays hidden.

Only PDF files work (export Word documents as PDF first).
