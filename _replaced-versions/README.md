## 🚀 How to View

### Direct Browser Opening
Simply double-click [`index.html`](index.html) from your Desktop folder to open it in Chrome, Safari, Edge, or Firefox. You can click any link in the top navigation bar to seamlessly move between pages!

### Local Development Server
From the folder in Terminal:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
